# 果岭读线与洞位规划系统

浏览器内运行的球场果岭管理工具:果岭档案、地形编辑、洞位规划、推杆模拟、赛事果岭图、设置。TypeScript + three.js,数据全部存 localStorage。

## 运行

```bash
pnpm install
pnpm dev
```

## 页面

- **果岭档案**:按 1-18 号洞管理,等高线 / 坡度箭头 / 坡度颜色三种视图,2D/3D 切换,可粘贴测量点(`x,y,z` 每行一个,米)重建地形
- **地形编辑**:笔刷拉高 / 压低 / 平滑 / 整平,松开鼠标自动保存
- **洞位规划**:红区为不合规位置(1m 内坡度超限或离边缘太近),点击放洞杯;一键生成 3 套十八洞方案,左中右 × 前中后九宫各两次自然均衡;同一位置周期内使用超限会提醒磨损
- **推杆模拟**:手动推杆(选起点、选方向、定速度)/ 读线辅助(反推瞄准点和力度,多档速度弯线同屏)/ 三推风险(从洞杯反推全果岭风险热力);时段(晨露 / 标准 / 下午干燥)与草纹顺逆都会影响滚动
- **赛事果岭图**:选一天的方案出十八洞图,标注洞位距前缘与侧边的步数,可直接打印
- **设置**:果岭速度、晨露、草纹、进洞速度、洞位规则、步长等参数;内置物理自检

## 物理模型

- 固定步长 1/480s 半隐式欧拉积分,无任何随机数:同一输入必然得到逐位相同的轨迹
- 摩擦系数由果岭速度反推:`μ = v₀² / (2·g·d)`,v₀ = 1.83 m/s(测速仪出球速度),d 为果岭速度值(英尺转米),平地停球距离与果岭速度定义严格一致(自检误差 < 0.1%)
- 坡度加速度沿坡面分解,草纹按速度方向与纹向夹角调制摩擦,晨露 / 干燥通过等效果岭速度体现
- 进洞判定:球心进入洞杯半径且速度不超过进洞速度;超速则记为擦洞

## 校验

```bash
node scripts/physics_check.mjs   # 停球距离 / 确定性 / 上下坡 / 进洞与擦洞
node scripts/readline_check.mjs  # 读线反推的瞄准点必须真实进洞
```
